# DeepSeek V4：金句和短句排比

状态：草稿，待测试。DeepSeek V4 用户反馈说禁词表会被当成提示，所以这里只描述写法，不列词。

```text
金句写法，指用「否定一个说法，再给另一个说法」制造顿悟感，再用几个句号切成短句：「她笑了。不是温暖的笑。而是幸福的笑。」「最扎心的不是分手，是分手后还得上班。」结尾再升华一句。读者会觉得作者在表演深刻，而不是在讲事。改法：直接写发生了什么、人物做了什么、说了什么。一个场景写完就停，不总结它的意义。
```
