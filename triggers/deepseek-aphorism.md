# DeepSeek V4：金句和短句排比

状态：草稿，待测试。只描述写法，不列禁词（V4 用户反馈：禁词表会被当成提示）。

```text
下面四组，左边是金句写法，右边是讲事的写法。照右边写。

1. 原：她笑了。不是温暖的笑。而是幸福的、充满爱的笑。
   改：她笑得很开心。

2. 原：我知道。你喜欢。我也喜欢。
   改：我知道你喜欢，我也喜欢。

3. 原：他语气平淡，像在说今天的天气。
   改：他没抬头：「嗯，知道了。」

4. 原：她靠在他肩上，什么也没说。这就够了。
   改：她靠在他肩上，什么也没说。

左边用「否定一个说法再给另一个」制造顿悟感，用句号把一句话切碎，结尾再补一句升华。读者会觉得作者在表演深刻。右边写发生了什么、人物做了什么、说了什么，场景写完就停。
```

来源：例 1、2 是 DeepSeek V4 用户反馈汇总里引用的原话，例 3、4 是同一报告列出的高频模板（「语气平淡，像在说今天的天气」10+ 人提及，「这就够了」15+ 人提及）。
