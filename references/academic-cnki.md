# 学术论文场景（知网、维普、万方）

用于毕业论文、期刊稿、课程论文、开题报告、基金申请书。先按模型 reference 改口癖，再按本文件处理学术文体特有的问题。

## 先说清楚三件事

1. **检测器的算法不公开。** 知网（CNKI）、维普、万方都没有公开 AIGC 检测的技术细节。网上流传的「知网看困惑度、维普看搭配、万方看风格一致性」大多出自降 AI 率工具的宣传文，没有官方出处。可以确定的只有：
   - 央视等报道把这类检测的原理概括为困惑度（文本是否「平滑」、好预测）和突发性（句子长短、复杂度起伏）。<https://news.qq.com/rain/a/20260624A0BCCS00>
   - 同一篇论文在不同平台的结果常常差很多，专家也说检测做不到 100% 准确，会误判。
2. **改写的目标是写得像一个具体的研究者，不是骗过检测器。** 不承诺降到多少。
3. **不编造。** 数据、文献、实验细节、访谈内容，原文没有的一律不加。降 AI 率最常见的翻车就是为了「加细节」编了一篇不存在的文献。

## 研究证据：AI 中文学术文本和人写的差在哪

- **HC3（Guo et al., 2023）**，中文子集，ChatGPT（GPT-3.5）对比人类专家回答：ChatGPT 回答平均更长（115 字 vs 102 字），但用词范围小得多（词表 4.5 万 vs 7.5 万）；语气更正式，情绪更少；用 GPT-2 类模型算困惑度，ChatGPT 文本集中在低困惑度区，人类文本有长尾。作者也提醒 ChatGPT 中文训练语料少，中文结论不一定精确。<https://arxiv.org/abs/2301.07597>
- **CCL 2023（Zhu et al.）**，《人工智能生成语言与人类语言对比研究——以 ChatGPT 为例》：算了 159 个语言特征，差异主要集中在「描述性特征、字词常用度、字词多样性」三个维度；句法复杂性、语篇凝聚力差异较小。<https://aclanthology.org/2023.ccl-1.46/>

翻成改写动作：**用词别太常见、别太单一**（字词常用度、多样性），**段落别都一样长、句子别都一样平**（描述性特征里的长度分布）。但这两条只是方向，具体改哪里，看下面的清单。

## 按章节的口癖

### AC-1 摘要

| 口癖 | 例子 | 改法 |
|---|---|---|
| 「本文旨在……」开头 | 本文旨在深入探讨 X 对 Y 的影响机制。 | 本文用 2018—2022 年 31 省面板数据，检验 X 对 Y 的影响。（先说用什么做了什么） |
| 「具有重要的理论意义和实践价值」 | 研究结果对……具有重要的理论意义和实践价值。 | 删。或换成一句具体的用处：「可用于估算……的阈值」。 |
| 「为……提供了新思路／理论支撑／参考」 | 为相关政策制定提供了理论支撑。 | 删，或说清楚提供了什么：「给出了补贴退坡的时间窗口」。 |
| 三连贡献 | 丰富了理论、拓展了视角、创新了方法 | 只留真有的那一项，展开说。 |
| GPT-6.x：摘要里强调局限 | 需要指出的是，本研究仅基于单一样本…… | 摘要不写局限，挪到讨论（见 `gpt-codex.md` A8）。 |

### AC-2 引言

| 口癖 | 例子 | 改法 |
|---|---|---|
| 「随着……的快速发展」 | 随着人工智能技术的快速发展，…… | 从具体问题或数据开头：「2023 年全国……达到……，但……」 |
| 「在……背景下」 | 在「双碳」目标背景下，…… | 同上；背景用一个事实说，不用「背景下」。 |
| 「……日益受到关注」 | 该问题日益受到学界关注。 | 给文献：「近五年已有……（张三，2022；李四，2024）」，没文献就删。 |
| 「然而，现有研究仍存在不足」 | 然而，现有研究仍存在以下不足：一是……二是……三是…… | 只写一个真正的空白，写清楚谁做了什么、缺了什么。 |

### AC-3 文献综述

| 口癖 | 例子 | 改法 |
|---|---|---|
| 逐个罗列「A 认为……B 指出……C 发现……」 | 王某（2020）认为……；李某（2021）指出……；张某（2022）发现…… | 按观点分组，写出分歧：「对 X 的作用，有两种看法。一种……（王某，2020；李某，2021）；另一种……」 |
| 「综上所述，现有研究……」段末总结 | 综上所述，现有研究已取得丰硕成果，但仍有待深化。 | 删。最后一句直接引出本文要做的事。 |
| 「研究表明」「有学者指出」不给出处 | 研究表明，…… | 补上作者年份；补不上就改成本文的判断，或删。 |

### AC-4 方法与数据

| 口癖 | 例子 | 改法 |
|---|---|---|
| 「采用……方法，以期全面……」 | 采用定性与定量相结合的方法，以期全面揭示…… | 写具体方法名、样本、变量：「用双重差分，以 2016 年政策为冲击……」 |
| 「科学性、合理性、有效性」 | 保证了研究的科学性和有效性。 | 删。说具体做了什么检验。 |
| GPT-6.x：「显式」「口径」「验收」 | 显式控制了……；统一了统计口径 | 控制了……；统一了统计方法 |

### AC-5 结果

| 口癖 | 例子 | 改法 |
|---|---|---|
| 「结果表明，……存在显著正相关关系」 | 结果表明，二者存在显著的正相关关系。 | 带数字和位置：「表 3 第（2）列，X 每增加 1 个单位，Y 提高 12.3 个百分点（p<0.01）」 |
| 「由此可见」「不难发现」 | 由此可见，…… | 删。 |
| 「此外，A 对 B 也有一定影响」 | 此外，年龄对结果也有一定影响。 | 给系数，或删（见 `gpt-codex.md` A9）。 |
| GPT-6.x：每个结果后跟「但这不能说明……」 | 这一结果不能证明二者存在因果关系。 | 只在读者真可能误读成因果时说一次，放在讨论里。 |

### AC-6 讨论与结论

| 口癖 | 例子 | 改法 |
|---|---|---|
| 「该发现与……的研究结论一致，进一步验证了……」 | 进一步验证了……理论的适用性。 | 说一致在哪、不一致在哪、为什么。 |
| 「本研究存在以下局限：一是……二是……三是……」 | 三条泛泛的局限（样本量、地域、时间） | 只写真正影响结论的那一条，说清楚会让结论偏向哪边。 |
| 「未来研究可以进一步……」 | 未来研究可以扩大样本、拓展领域、深化机制。 | 写一个可以检验的具体问题。 |
| 「对策建议：一要……二要……三要……」 | 一要加强顶层设计，二要完善体制机制，三要强化人才支撑。 | 每条建议对应本文的一个发现；对应不上的删。 |

## 跨章节的词

这些词单独出现不算问题，一页出现好几个、或者句句都有，就要改。

| 词 | 改法 |
|---|---|
| 深入探讨、深刻揭示、系统梳理 | 分析、说明、梳理（去掉修饰词） |
| 至关重要、不可或缺、举足轻重 | 说清楚缺了会怎样 |
| 显著（非统计意义上） | 只在有统计检验时用 |
| 有效、充分、全面 | 删，或给数字 |
| 起到了……的作用、发挥了……作用 | 直接用动词：「降低了」「推动了」 |
| 进行……分析 / 研究 / 探讨 | 分析 / 研究 / 探讨（去掉「进行」） |
| 首先、其次、再次、最后 | 按逻辑关系连接；确实是并列步骤可以保留 |
| 值得注意的是、需要指出的是 | 删 |
| 综上所述、总而言之 | 删，或只在全文结论第一句用一次 |
| 不仅……而且……、不是……而是…… | 一章最多一次 |
| 赋能、助力、抓手、闭环、底层逻辑 | 学术文本里一律换掉 |

## 改写原则（学术场景的特殊要求）

- **术语不换。** 同一个概念全文一个叫法，不做同义替换。为降 AI 率把「碳排放强度」换成「碳排放密度」，比 AI 味更糟。
- **引文、公式、表格、数据原样保留。**
- **不口语化。** 去掉 AI 腔不等于改成聊天口气。「笔者」「本文」照用。
- **允许不对称。** 最重要的发现多写，次要的一句带过。AI 稿件的典型样子是每一点写得一样长。
- **改写后通读一遍查重率。** 有文章提醒，盲目改写可能破坏逻辑、术语和格式，甚至让重复率反弹。

## 不做的事

- 不教「中英互译洗稿」「插入错别字」「把句号换成逗号」之类对抗检测器的手法。这些手法伤可读性，学校也可能认定为学术不端。
- 不替用户写论文中原本没有的部分（新实验、新访谈、新文献）。
- 用户问「改完能不能过知网」，如实回答：不知道，检测器不公开，结果因平台和版本而异。
